# Imágenes de la página de ventas

Carpeta de recursos gráficos de la carta. Todo lo que esté en `public/` se sirve
desde la raíz del sitio, así que un archivo aquí se referencia como `/img/NOMBRE`.

## Archivos

- **`logo.png`** — logotipo de Emilse Rios (PNG transparente). Se usa en el hero.
- **`foto.jpg`** — foto de Emi con el contrabajo, para la apertura de la carta.
- **`clef-cursor.svg`** — cursor personalizado con forma de clave de fa (solo
  navegadores de escritorio; en los que no soportan cursores SVG cae al normal).

> Nota: si reemplazas `logo.png` o `foto.jpg`, conserva el mismo nombre para que
> el código los tome sin cambios.
